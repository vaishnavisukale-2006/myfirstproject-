# 🚀 My First Website

Welcome to **My First Website**! A clean, modern, and interactive website built from scratch using pure **HTML5**, **CSS3**, and **JavaScript** (no complicated bundlers or frameworks required).

---

## 📁 Project Structure

```
myfirstproject/
├── index.html     # Semantic HTML5 markup and page layout
├── style.css      # Modern Vanilla CSS design system (Dark/Light themes, glassmorphism, responsive grid)
├── script.js      # Vanilla JavaScript logic (Theme toggle, interactive widgets, local storage)
└── README.md      # Beginner guide & documentation
```

---

## ✨ Features Included

- **🌗 Dark & Light Mode**: Instant toggle with smooth color transitions and saved preference in `localStorage`.
- **👋 Dynamic Greeting**: Automatically detects the time of day and shows a personalized greeting (Morning, Afternoon, Evening).
- **💡 Coding Fun Fact Generator**: Generates fun and inspiring computer science facts at the click of a button.
- **🎮 Interactive Playground**:
  - **Click Counter & Milestone Celebrations**: Event-driven counter with celebration toast alerts on milestones (10, 25, 50, 100).
  - **Color Palette Generator**: Generates vibrant modern palettes with live preview and one-click HEX clipboard copying.
  - **Coding Goals / To-Do Tracker**: Add, complete, and delete goals with automatic `localStorage` persistence.
- **✉️ Contact Form**: Interactive form with live field validation and toast notifications.
- **📱 Fully Responsive**: Fluid design that automatically adapts to mobile phones, tablets, and desktop displays.
- **⬆️ Back to Top**: Smooth scroll-to-top floating button.

## 🚀 How to Run the Website

### Option 1: Direct in Browser
Simply double-click the `index.html` file or right-click and choose **Open with > Chrome / Edge / Firefox / Safari**.

### Option 2: Using VS Code Live Server / Local Server
If using VS Code or any IDE:
1. Install the **Live Server** extension.
2. Click **Go Live** at the bottom status bar or right-click `index.html` and select **Open with Live Server**.
