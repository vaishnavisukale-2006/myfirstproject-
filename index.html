I decided to take the leap into web development. Instead of just reading tutorials, I wanted to build a real, functioning, responsive webpage with my own hands.

This website combines clean semantic structure, custom CSS variables, responsive flexbox & grid layouts, dark mode with local storage, and real JavaScript mini-apps!
